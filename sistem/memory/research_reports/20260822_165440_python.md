# python — Araştırma Raporu

## Bulunan Kaynaklar
- **Python**: Python, nesne yönelimli, yorumlamalı, birimsel (modüler) ve etkileşimli yüksek seviyeli bir programlama dilidir. Girintilere dayalı basit söz dizimi, dilin
- **Monty Python**: Monty Python, bir Britanyalı komedi grubu. Monty Python komedi grubu şu üyelerden oluşur. Graham Chapman (1941-1989) John Cleese (d. 1939) Terry Gilliam
- **Python Yazılım Vakfı**: Python Yazılım Vakfı (İngilizce: Python Software Foundation, kısaca PSF) 6 Mart 2001 tarihinde Python programlama dilini korumak, geliştirmek ve uluslararası
- **Python değişkenleri**: Vikipedi&#039;ye uygun olmayan bilgiler Vikikitap&#039;a da taşınamazlar. Bu değişkenler Python Programlama Diline aittir. Bu kodlar ileri programcılık bilgisi gerektirir
- **Python Imaging Library**: Python Imaging Library (kısaca PIL), Python programlama dili için geliştirilen, açık kaynak kodlu grafik işleme kütüphanesidir. Bu kütüphane, içinde barındırdığı
